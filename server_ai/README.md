# LifeKaFunda Self-Hosted AI Background Remover

100% Free, Unlimited, Studio-Quality Background Removal using Rembg & U2Net.

## How to Run on Server / Local:

1. Install Python 3.9+ if not installed.
2. Run:
   ```bash
   pip install -r requirements.txt
   python app.py
   ```
3. The AI service will start on `http://127.0.0.1:5005`.
4. LifeKaFunda frontend and backend will automatically detect and route all background removal requests to this studio AI!
